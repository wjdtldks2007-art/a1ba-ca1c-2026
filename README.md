# 2026 알바 실수령액 · 주휴수당 계산기

2026년 최저시급 10,320원 기준으로 아르바이트 월급 실수령액을 계산하는 웹페이지입니다.
시급·하루 근무시간·주 근무일수를 넣으면 주휴수당, 3.3% 원천징수, 4대보험(9.72%)까지 반영한 금액이 바로 나옵니다.

- 사용 주소: https://wjdtldks2007-art.github.io/a1ba-ca1c-2026/
- 파일: `index.html` 하나 (HTML/CSS/JS 모두 포함, 서버·설치 필요 없음)

## 계산 방식

| 항목 | 기준 |
| --- | --- |
| 최저시급 | 2026년 10,320원 |
| 주휴수당 | 주 15시간 이상 근무하고 그 주 근무일을 모두 채운 경우, 1일 소정근로시간(최대 8시간) × 시급 |
| 3.3% 원천징수 | 사업소득(프리랜서) 처리 시 소득세 3% + 지방소득세 0.3% |
| 4대보험 | 근로자 부담분 약 9.72% (국민연금 4.75% + 건강보험 3.595% + 장기요양 건강보험료의 13.14% + 고용보험 0.9%) |

## 고치기

`index.html`을 열어 필요한 부분을 수정하고, 같은 저장소 `main` 브랜치에 올리면 1분 안에 사이트에 반영됩니다.

- 시급·보험료율: 파일 안 `계산 상수` 블록 (`MIN_WAGE_2026`, `RATE_PENSION`, `RATE_HEALTH` 등)
- 광고 넣을 자리: `[광고 삽입 위치 A]`, `[광고 삽입 위치 B]` 주석 아래
- 공유 미리보기 이미지: 1200×630 `og-image.png`를 올리고 `og:image` 주석 풀기
